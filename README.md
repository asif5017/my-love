# Little Love Book

একটি ছোট responsive HTML/CSS/JavaScript ওয়েবসাইট।

## চালানোর নিয়ম
1. `index.html` ফাইলটি ব্রাউজারে খুললেই চলবে।
2. নিজের লেখা বদলাতে `index.html`-এর JavaScript অংশে `pages` array-এর `title`, `text`, `emoji` পরিবর্তন করো।
3. GitHub Pages-এ প্রকাশ করতে repository-তে `index.html` আপলোড করো। Root folder-এ রাখলে সাধারণত সরাসরি কাজ করবে।

ফন্ট লোড করার জন্য ইন্টারনেট থাকলে Google Fonts ব্যবহার হবে; ইন্টারনেট না থাকলেও সাইটটি চলবে।
